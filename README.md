# 基于 FreeRTOS 的智能手表多级菜单系统

一款基于 STM32F103C8T6 与 FreeRTOS 的智能手表固件，搭配 0.96 寸 SSD1306 OLED（128x64，I2C，u8g2 渲染），实现多级菜单交互界面与信息显示。

## 功能特性

- 多级菜单交互界面，菜单切换流畅。
- 实时时钟：顶部显示日期与小时，下方用大字显示 `MM:SS`。
- 分钟/秒数字向上滚动的平滑动画，类似机械表盘翻字。
- 非阻塞全功能按键，支持菜单切换与时间设置。
- 附加界面：秒表（毫秒计）、日历、温湿度（DHT11）、手电筒、多级菜单。

## 系统设计

基于 FreeRTOS 进行多任务划分：

- UI 显示任务：负责 OLED 渲染与界面动画。
- 传感器采集任务：读取 DHT11 等传感数据。
- 按键输入任务：扫描按键并通过消息队列上报。

各任务之间通过 FreeRTOS 消息队列进行通信与数据同步。

## 硬件组成

- 主控：STM32F103C8T6（ARM Cortex-M3）
- 显示屏：SSD1306 0.96 寸 128x64 OLED，I2C 接口，u8g2 驱动
- 输入：多路按键
- 输出：OLED、蜂鸣器
- 传感器：DHT11（温湿度）

## 软件栈

- FreeRTOS：多任务调度 + 1 秒软件定时器驱动时钟。
- u8g2（全缓冲 + I2C）：负责 OLED 渲染。
- STM32 HAL：由 STM32CubeMX 生成。
- 编译工具：Keil MDK-ARM 或 IAR EWARM。

## 项目亮点

- 用 FreeRTOS 做多任务划分，UI 显示、传感器采集、按键输入各占一个任务，任务间用消息队列同步数据。
- 菜单切换采用平滑动画：通过偏移量累加实现光标与菜单内容联动滑动，避免滑出残影与坐标错位。
- 时间数字滚动动画按实际运行时间（毫秒）推进，并把每个数字裁剪到各自显示格内，保证流畅且不越界。
- OLED I2C 总线运行在 400 kHz，保证界面刷新足够流畅。

## 构建与烧录

- 用 STM32CubeMX 打开 `mywatch.ioc` 重新生成代码，或直接用 Keil 打开 `MDK-ARM/` 工程（IAR 用 `EWARM/`）。
- 编译后烧录到 STM32F103C8T6。
