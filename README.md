# Smart OLED Watch (STM32)

A feature-rich wristwatch built on an **STM32F103C8T6** with a **0.96" SSD1306 OLED** (128x64, I2C). It runs on **FreeRTOS** and uses the **u8g2** graphics library.

## Features

- Real-time clock: date + hour on top, big `MM:SS` display below.
- Smooth **rolling / odometer** digit animation for the minutes and seconds digits.
- Manual time & date setting through a key-driven menu, with buzzer feedback.
- Additional screens: stopwatch (millisecond), calendar, temperature & humidity (DHT11), flashlight, wooden-fish timer, and settings.
- Menu navigation with hardware buttons.

## Hardware

- MCU: STM32F103C8T6 (ARM Cortex-M3)
- Display: SSD1306 0.96" 128x64 OLED over I2C (driven by u8g2)
- Input: multiple push buttons
- Output: buzzer, OLED
- Sensor: DHT11 (temperature / humidity)

## Software Stack

- FreeRTOS — tasks per screen + a 1 s software timer for the clock tick.
- u8g2 (full-buffer, I2C) — rendering the OLED.
- STM32 HAL (generated by CubeMX).
- Build with **Keil MDK-ARM** or **IAR EWARM**.

## Build & Flash

- Open `mywatch.ioc` in STM32CubeMX to regenerate, or open the Keil project in `MDK-ARM/` (or the IAR project in `EWARM/`).
- Build and flash to the STM32F103C8T6 target.

## Highlights

- The clock tick is driven by a FreeRTOS software timer; the display is updated in its own task.
- The rolling digit effect clips each glyph to its cell and animates by elapsed wall-clock time, so it stays smooth and never leaves the allocated screen area.
- The OLED I2C bus runs at 400 kHz to keep the animation fluid.
