# 智能 OLED 手表（STM32）

一款功能丰富的智能手表，主控 **STM32F103C8T6**，搭配 **0.96 寸 SSD1306 OLED**（128x64，I2C），运行 **FreeRTOS** 实时操作系统，使用 **u8g2** 图形库进行显示。

## 功能特性

- **实时时钟**：顶部显示日期与小时，下方用大字显示 `MM:SS`。
- **平滑滚动动画**：分钟/秒的每个数字像机械表盘一样向上滚动，切换自然流畅。
- **设置功能**：通过按键菜单手动调整时间与日期，带蜂鸣器反馈。
- **附加界面**：秒表（毫秒计）、日历、温湿度（DHT11）、手电筒、木鱼计时、系统设置。
- **菜单导航**：多路硬件按键操作。

## 硬件组成

- 主控：STM32F103C8T6（ARM Cortex-M3）
- 显示屏：SSD1306 0.96 寸 128x64 OLED，I2C 接口，u8g2 驱动
- 输入：多路按键
- 输出：OLED、蜂鸣器
- 传感器：DHT11（温湿度）

## 软件栈

- **FreeRTOS**：每个界面一个任务，用 1 秒软件定时器驱动时钟。
- **u8g2**（全缓冲 + I2C）：负责 OLED 渲染。
- **STM32 HAL**：由 STM32CubeMX 生成。
- 编译工具：Keil MDK-ARM 或 IAR EWARM。

## 构建与烧录

- 用 STM32CubeMX 打开 `mywatch.ioc` 重新生成代码，或直接用 Keil 打开 `MDK-ARM/` 工程（IAR 用 `EWARM/`）。
- 编译后烧录到 STM32F103C8T6。

## 项目亮点

- 时钟由 FreeRTOS 软件定时器驱动，显示刷新在独立任务中进行。
- 滚动数字效果将每个数字裁剪到各自显示格内，并按**真实时间（墙钟毫秒）**推进动画，保证流畅且不越界。
- OLED I2C 总线运行在 **400 kHz**，确保动画足够流畅。
